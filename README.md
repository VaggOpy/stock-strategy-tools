# Εργαλεία ανάλυσης και αξιολόγησης στρατηγικών μετοχών με χρήση LLM

Ειδικό θέμα, Τμήμα Ηλεκτρολόγων Μηχανικών και Μηχανικών Υπολογιστών, Πανεπιστήμιο Θεσσαλίας.
Βαγγέλης Πλυτάς, επιβλέπων Γ. Θάνος.

Το εργαλείο κατεβάζει ημερήσιες τιμές και θεμελιώδη στοιχεία για μετοχές και ETFs, τα δείχνει σε
διαγράμματα με τεχνικούς δείκτες και τρέχει backtest σε στρατηγικές. Το κύριο ερευνητικό κομμάτι
είναι η επιλογή υπερπαραμέτρων: πώς διαλέγεις π.χ. το μήκος ενός EMA ώστε να δουλεύει και σε
δεδομένα που δεν έχεις δει, και όχι μόνο σε αυτά που βελτιστοποίησες. Αυτό μελετάται με walk-forward
αξιολόγηση και σύγκριση διαφορετικών μεθόδων (σταθερές τιμές, grid search, Optuna και μερικές πιο
συντηρητικές επιλογές).

Επίσης περιλαμβάνει:
- αλγόριθμο επιλογής μετοχών με βάση momentum, θεμελιώδη και δύναμη κλάδου, με backtest του καλαθιού
- περιγραφή στρατηγικής σε φυσική γλώσσα, την οποία ένα LLM μετατρέπει σε κανόνες που μετά τρέχουν στο backtest
- web εφαρμογή σε Streamlit

Όλα τα αποτελέσματα συγκρίνονται με buy & hold του SPY.

## Σχεδιαστικές επιλογές

Μια στρατηγική περιγράφεται σε JSON, από μια κλειστή λίστα δεικτών και συνθηκών. Την ίδια περιγραφή
τη διαβάζουν το backtest, ο optimizer και το LLM. Το LLM δεν γράφει κώδικα. Παράγει μόνο αυτό το JSON,
που ελέγχεται με schema πριν τρέξει.

Για να μην υπάρχει look-ahead bias, το σήμα βγαίνει με το κλείσιμο της μέρας και η συναλλαγή γίνεται στο
άνοιγμα της επόμενης. Τα θεμελιώδη μπαίνουν από την ημερομηνία που κατατέθηκαν στην SEC και όχι από το
τέλος του τριμήνου (στην Apple η διαφορά είναι περίπου ένας μήνας). Υπάρχει και test που κόβει τα
δεδομένα σε μια ημερομηνία και ελέγχει ότι μέχρι εκεί τα αποτελέσματα δεν αλλάζουν.

Χρησιμοποιούνται μόνο δωρεάν πηγές δεδομένων. Τι δίνει η καθεμία και με ποια όρια:
[docs/πηγές_δεδομένων.md](docs/πηγές_δεδομένων.md).

## Δομή

Όλη η λογική είναι στο `src/tradetool/` και δεν εξαρτάται από το Streamlit, ώστε να ελέγχεται με tests.
Η εφαρμογή και τα πειράματα απλώς τη χρησιμοποιούν.

```
src/tradetool/
  config.py              διαδρομές, σταθερή περίοδος πειραμάτων (TEST_START, TEST_END), ανάγνωση .env
  data/
    universe.py, .csv    οι μετοχές (S&P 500 + Nasdaq-100) και τα ETFs, με κλάδο SIC
    prices.py            ημερήσιες τιμές από Alpaca, έλεγχος με Yahoo, καθαρισμός
    fundamentals.py      θεμελιώδη από τη SEC με την ημερομηνία κατάθεσης (χωρίς look-ahead)
    checks.py            έλεγχοι ακεραιότητας των αποθηκευμένων δεδομένων
    setup.py             python -m tradetool.data.setup: κατεβάζει όλα τα δεδομένα
  indicators/
    core.py              SMA, EMA, Bollinger, Donchian, RSI, ATR, MACD
    registry.py          κάθε δείκτης με τις παραμέτρους και τα επιτρεπτά εύρη τους
  rules/
    schema.py            η μορφή JSON των στρατηγικών και ο έλεγχός της
    signals.py           κανόνας -> σήματα εισόδου/εξόδου
    describe.py          ο κανόνας σε απλά ελληνικά, για να βλέπει ο χρήστης τι θα τρέξει
    library/*.json       τέσσερις κλασικές στρατηγικές
  backtest/
    engine.py            η προσομοίωση μίας μετοχής (εκτέλεση στο επόμενο άνοιγμα, stops, κόστη)
    portfolio.py         η προσομοίωση καλαθιού με αλλαγή βαρών κάθε μήνα
    metrics.py           CAGR, Sharpe, drawdown κ.λπ. και σύγκριση με buy & hold και SPY
  optimize/
    search.py            πλέγμα παραμέτρων, αποδόσεις όλων των συνδυασμών
    walkforward.py       διαστήματα εκπαίδευσης/ελέγχου και οι μέθοδοι επιλογής παραμέτρων
  selection/
    factors.py           momentum και θεμελιώδη ανά μήνα, μόνο με ό,τι ήταν γνωστό τότε
    groups.py            ομάδες μετοχών (κλάδος SIC ή clustering) και δύναμη ομάδας
    model.py             σκορ, καλάθι των N καλύτερων, περιορισμός στις μετοχές του S&P 500 κάθε ημερομηνίας
  llm/
    client.py            Gemini ή Ollama με την ίδια κλήση, και cache των απαντήσεων στον δίσκο
    prompts.py           τα κείμενα προς το LLM, φτιαγμένα από τη λίστα δεικτών και τη βιβλιοθήκη κανόνων
    strategy.py          κείμενο -> έλεγχος -> διόρθωση -> κανόνας, και εξήγηση των αποτελεσμάτων
  charts/                γραφήματα plotly (τιμές, backtest, χάρτες ευαισθησίας)
app/
  Home.py                streamlit run app/Home.py
  views/                 μία σελίδα ανά αρχείο: αρχική, διαγράμματα, backtest, υπερπαράμετροι,
                         επιλογή μετοχών, στρατηγική με λόγια
experiments/             ένα script ανά πείραμα, τα αποτελέσματα στο results/<όνομα script>/
docs/                    μέθοδοι και αποτελέσματα σε κείμενο
tests/                   pytest, μαζί με τα tests για look-ahead
```

Τα docs με τη σειρά που αξίζει να διαβαστούν:
[πηγές δεδομένων](docs/πηγές_δεδομένων.md), [θεμελιώδη](docs/θεμελιώδη.md), [backtest](docs/backtest.md),
[επιλογή υπερπαραμέτρων](docs/υπερπαράμετροι.md), [επιλογή μετοχών](docs/επιλογή_μετοχών.md),
[στρατηγική με λόγια](docs/στρατηγική_με_λόγια.md).

## Εγκατάσταση

Python 3.12.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-lock.txt
pip install -e .
python -m tradetool.data.setup
```

Το τελευταίο κατεβάζει τα δεδομένα στο `data/` (δεν είναι στο git): τιμές για τα 540 σύμβολα σε περίπου 5 λεπτά
και τα θεμελιώδη της SEC από ένα έτοιμο στιγμιότυπο. Κλειδιά δεν χρειάζονται. Χωρίς κλειδιά Alpaca οι τιμές
έρχονται μόνο από το Yahoo, οπότε τα νούμερα μπορεί να διαφέρουν λίγο από αυτά των docs (βλ.
[docs/πηγές_δεδομένων.md](docs/πηγές_δεδομένων.md)). Για τα ίδια δεδομένα με τα πειράματα:

```
copy .env.example .env
```

και συμπλήρωση στο `.env` των κλειδιών Alpaca και ενός email για τη SEC (`SEC_USER_AGENT`). Με
`python -m tradetool.data.setup --sec` τα θεμελιώδη κατεβαίνουν απευθείας από τη SEC (περίπου 17 λεπτά).

Τα αποτελέσματα των πειραμάτων είναι ήδη στο `experiments/results/`, οπότε για να τα δει κανείς δεν χρειάζεται
να τρέξει τίποτα. Η εφαρμογή δουλεύει και χωρίς το setup: κατεβάζει τα δεδομένα κάθε μετοχής όταν την ανοίγεις.

Για τη σελίδα «Στρατηγική με λόγια» χρειάζεται ένα LLM: δωρεάν κλειδί Gemini από το
https://aistudio.google.com/apikey στο `GEMINI_API_KEY` του `.env`, ή τοπικά το Ollama
(`ollama pull qwen2.5:3b`). Οι υπόλοιπες σελίδες δεν το χρειάζονται.

Σε Windows, αν το path του project έχει ελληνικούς χαρακτήρες, το `pip install -e .` αποτυγχάνει (η Python 3.12
γράφει τα `.pth` σε cp1252). Με λατινικό path δουλεύει κανονικά.

## Χρήση

```
streamlit run app/Home.py
pytest
python experiments/classic_strategies.py
python experiments/walkforward_methods.py
python experiments/stock_selection.py
python experiments/llm_rules.py
python experiments/check_adjustments.py
```

Τα tests τρέχουν και στο GitHub σε κάθε push, χωρίς δεδομένα. Όσα ελέγχουν τα ίδια τα δεδομένα
(`tests/test_data_cache.py`) τρέχουν μόνο τοπικά, όταν υπάρχει ο φάκελος `data/`.
